# Glosario
| Término | Significado |
|---|---|
| Reserva | Volumen descubierto, recuperable, comercial y remanente a la fecha, ligado a un proyecto de desarrollo. |
| Recurso | Volumen aún no reserva: contingente (descubierto, no comercial) o prospectivo (no descubierto). |
| 1P | Probadas. Al menos 90 % de probabilidad (P90) de recuperar ese volumen o más. |
| 2P | Probadas + probables. Al menos 50 % (P50). Estimado central. |
| 3P | Probadas + probables + posibles. Al menos 10 % (P10). Escenario optimista. |
| MMB | Millones de barriles. |
| MMMPC | Miles de millones de pies cúbicos de gas (≈ "Bcf"). |
| MMBPCE | Millones de barriles de petróleo crudo equivalente. En este archivo 1 MMMPC ≈ 0.2 MMBPCE (estimado por regresión). |
| Condensado | Líquido que se separa de un gas húmedo. |
| Volumen original | Hidrocarburo total en sitio; la reserva es la parte recuperable. |
| Clúster | Campos evaluados en conjunto; la reserva aparece en uno y los demás en cero. |
| Certeza 1P/3P | Porcentaje del 3P que ya está probado (derivada). |
Fuente de definiciones 1P/2P/3P: [Marco conceptual de reservas, CNH (gob.mx)](https://www.gob.mx/cms/uploads/attachment/file/485719/10-Marco_Conceptual_Reservas_Hidrocarburos.pdf).
